# 实验目的

## 一、研究背景

随着工业4.0和智能制造的快速发展，多机械臂协同作业在现代生产线中的应用日益广泛。传统的多机械臂调度方法通常依赖于预设的固定规则或人工编程，难以适应复杂多变的生产需求。大语言模型（LLM）的出现为智能调度系统提供了新的可能性，能够从自然语言指令中理解任务需求并动态生成调度策略。

## 二、实验目的

### 2.1 核心目标

本实验旨在构建一个**基于LLM与Harness Engineering的多机械臂调度智能体系统**，实现以下核心目标：

1. **LLM驱动的智能调度**：利用大语言模型的自然语言理解和推理能力，从自然语言指令中自动分解任务、分配资源并生成调度策略。

2. **Harness Engineering约束框架**：设计并实现一个完整的约束框架，包含任务分解、资源分配、结果验证与异常处理等模块，确保调度系统的可靠性和可追溯性。

3. **闭环反馈机制**：建立仿真执行结果向Harness的实时回传机制，实现调度策略和代码生成策略的动态调整与持续优化。

4. **自动化代码生成**：为每个机械臂自动生成可执行的行为代码，基于任务需求动态编排原子技能原语，而非依赖预置的固定技能库。

### 2.2 技术目标

1. **仿真验证集成**：接入Isaac Sim、Omniverse或Isaac Lab仿真接口，完成调度方案的执行验证。

2. **基准数据集测试**：利用开源工业数据集（如MRTA-Benchmark、哈工大工业智能数据集）构建不少于4个操作节点、2个工件的产线场景。

3. **性能评估**：建立包含makespan、任务成功率、资源利用率及违反约束次数的综合评估体系。

### 2.3 预期成果

1. 完整的多机械臂调度智能体系统代码
2. Harness框架设计文档
3. 仿真测试报告
4. 评估对比结果（与基准方法的对比）

## 三、研究意义

### 3.1 理论意义

1. 探索LLM在工业调度领域的应用范式
2. 验证Harness Engineering在复杂控制系统中的有效性
3. 研究闭环反馈机制对调度性能的影响

### 3.2 实践意义

1. 降低多机械臂系统编程门槛
2. 提高生产线调度的灵活性和适应性
3. 为智能制造提供可复用的解决方案

## 四、创新点

1. **LLM与Harness的深度融合**：将大语言模型的智能推理能力与工程约束框架相结合，实现既智能又可靠的调度系统。

2. **动态代码生成**：摒弃传统的固定技能库模式，基于任务需求动态生成机械臂行为代码。

3. **闭环反馈优化**：建立从仿真结果到调度策略的实时反馈通道，实现系统的自适应优化。

4. **多维度评估体系**：建立包含时间效率、成功率、资源利用和约束满足的综合评估框架。
