## 1. 评估方法

### 评估指标

| 指标 | 定义 | 优化方向 |
|------|------|----------|
| Makespan | 总完工时间 | 最小化 |
| 任务成功率 | 成功任务数 / 总任务数 | 最大化 |
| 资源利用率 | 忙碌时间 / (makespan × num_arms) | 最大化 |
| 约束违反次数 | 时间重叠 + 能力不匹配 | 最小化 |

### 对比方法

| 方法 | 描述 |
|------|------|
| **Agent (LLM)** | 本系统 |
| **Greedy (LPT)** | 最长处理时间优先贪心 |
| **Random** | 随机分配 |
| **Optimal** | MILP 最优解 |

### 评估协议

- 每场景运行 5 次（seeds: 42-46）
- 报告均值 ± 标准差
- 配对 t 检验，α = 0.05
