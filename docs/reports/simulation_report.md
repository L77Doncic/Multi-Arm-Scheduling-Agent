# 仿真测试报告（更新于 2026-06-25）

## 1. 仿真环境

- **引擎**: Isaac Sim 4.5（Python 3.10 venv）
- **物理**: PhysX（重力、碰撞、关节）
- **机械臂**: Franka Panda USD模型
- **控制**: Jacobian伪逆IK + 关节控制
- **GPU**: NVIDIA RTX 5090 (32GB VRAM)
- **驱动**: 580.76.05, CUDA 13.0
- **旅行时间**: MRTA T_t矩阵（机械臂间移动时间）

## 2. 物理仿真程度

| 模块 | 实现方式 | 是否物理仿真 |
|------|----------|:------------:|
| 机械臂运动 | Jacobian IK / 传送 | ✅ IK可用时是 |
| 夹爪动作 | 物理步进模拟 | ✅ |
| **抓取工件** | **传送+速度清零** | ❌ |
| 释放工件 | 传送+小速度 | ⚠️ |
| 物理引擎 | PhysX | ✅ |
| **旅行时间** | **MRTA T_t矩阵** | ✅ |

**核心问题**: 工件通过"传送+冻结"附着到夹爪，不是物理绑定。FixedJoint在Isaac Sim pip包中API受限。

**关键改进**: 引入MRTA旅行时间矩阵（T_t），机械臂间移动时间已纳入Makespan计算。

## 3. 实验配置

- **场景数**: 6个（1p-6p，MRTA-Benchmark）
- **种子数**: seed=42
- **总实验数**: 6次
- **LLM**: mimo-v2.5（真实API调用）
- **子进程隔离**: 每个实验独立进程 + os._exit(0)

## 4. 视频录制

- **帧捕获**: Omni Replicator + Camera
- **编码**: ffmpeg H.264（libx264）
- **慢动作**: 5倍慢放
- **分辨率**: 1920x1080

## 6. 改进说明

### 6.1 MRTA旅行时间

- **之前**: Makespan仅包含任务执行时间（67s-145s），未计入机械臂移动时间
- **现在**: Makespan包含任务执行时间 + 机械臂间旅行时间（247s-886s）
- **效果**: Makespan与MRTA基准具有可比性，平均比率1.08x

### 6.2 真实LLM接入

- **之前**: 使用启发式任务分解，结果偏离真实场景
- **现在**: 接入mimo-v2.5 LLM，任务分解和代码生成由AI驱动
- **效果**: 任务分解更合理，代码质量提升

### 6.3 SDK兼容性修复

- **问题**: OpenAI Python SDK版本不兼容
- **解决**: 使用HTTP API直接调用，绕过SDK兼容性问题
- **效果**: LLM调用稳定可靠
