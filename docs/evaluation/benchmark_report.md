<h1 style="text-align: center">评估对比结果报告</h1>

## 1. 评估背景

### 1.1 MRTA-Benchmark 数据集

本次评估使用 MRTA-Benchmark 数据集，该数据集由 TU Delft 在 APEX-MR（Assembly Process EXecution for Multi-Robot systems）项目中提出，发表于 RSS 2025（Robotics: Science and Systems）。数据集源自 LEGO 积木装配任务，包含 13 个装配场景，每个场景定义了任务序列、机械臂配置和旅行时间矩阵。该数据集为多机器人任务分配领域提供了标准化的评估基准。

在本系统中，我们将 MRTA-Benchmark 的旅行时间数据集成到 6 个产线场景（1p-6p）中，每个场景包含：

- 8 个任务（包括 pick、assemble、inspect、package 等操作）
- 3 个机械臂
- 4 个工位
- 完整的 MRTA 旅行时间矩阵（$T_e$ 和 $T_t$）

### 1.2 评估目标

本次评估旨在回答以下研究问题（Research Questions, RQs）：

1. **RQ1**：LLM 驱动的调度系统与 MILP 最优解的 makespan 差距有多大？
2. **RQ2**：系统的任务成功率和资源利用率如何？
3. **RQ3**：不同场景规模对系统性能有何影响？
4. **RQ4**：Agent 调度结果与 MILP 基线的差异是否具有统计显著性？

### 1.3 评估框架

评估框架基于 `evaluation/` 模块实现，包含以下组件：

- `MetricsCalculator`：计算 makespan、成功率、利用率、违反数四项指标
- `BenchmarkRunner`：运行 Agent 并收集指标，支持与基线对比
- `ComparisonReport`：生成对比报告，包含改进百分比和 $p$ 值


## 2. 评估指标定义

本节详细定义评估中使用的四个核心指标，包括其数学公式、取值范围和物理含义。

### 2.1 Makespan（完工时间）

Makespan 是调度优化中最核心的指标，定义为从第一个任务开始到最后一个任务结束的总时间跨度。

$$\text{Makespan} = \max_{e \in E}(e.\text{end\_time}) - \min_{e \in E}(e.\text{start\_time})$$

其中 $E$ 为执行日志中的任务条目集合，每个条目 $e$ 包含 `start_time` 和 `end_time` 字段。当 $E = \emptyset$ 时，$\text{Makespan} = 0$。

Makespan 越小表示调度效率越高。在多机械臂系统中，最优 makespan 取决于任务的并行执行程度和机械臂间的负载均衡。

**Makespan 比率**定义为 Agent 调度 makespan 与 MILP 最优 makespan 之比：

$$R_{\text{makespan}} = \frac{\text{Makespan}_{\text{Agent}}}{\text{Makespan}_{\text{MILP}}}$$

当 $R < 1$ 时，Agent 调度优于 MILP 基线；当 $R > 1$ 时，Agent 调度劣于 MILP 基线；当 $R = 1$ 时，两者性能相同。

### 2.2 Task Success Rate（任务成功率）

任务成功率衡量任务执行的可靠性，定义为成功完成的任务数占总任务数的比例。

$$\text{Success Rate} = \frac{|\{e \in E : e.\text{status} = \text{"completed"}\}|}{|E|}$$

其中 $e.\text{status}$ 的取值为 `"completed"`、`"failed"` 或 `"cancelled"`。当 $E = \emptyset$ 时，$\text{Success Rate} = 1$（空集视为平凡满足）。

任务成功率为 1.0（100%）表示所有任务均成功完成。影响成功率的因素包括：

- 仿真执行中的物理约束违反（如 pick 距离超限）
- 代码生成错误（如语法错误、参数不匹配）
- 超时（任务执行时间超过设定阈值）
- 异常恢复失败（重试次数耗尽）

### 2.3 Resource Utilization（资源利用率）

资源利用率衡量机械臂的使用效率，定义为所有臂的忙碌时间占比的平均值。

$$\text{Utilization} = \frac{\sum_{e \in E}(e.\text{end\_time} - e.\text{start\_time})}{\text{Makespan} \times N_{\text{arms}}}$$

其中 $N_{\text{arms}}$ 为机械臂数量（本实验中为 3）。利用率通过 `clamp` 函数限制在 $[0, 1]$ 范围内。

资源利用率的取值范围为 $[0, 1]$。理论上，当所有机械臂在整个 makespan 期间均处于忙碌状态时，利用率为 1.0。实际中，由于任务依赖和空闲等待，利用率通常低于 1.0。

**利用率与 makespan 的关系**：在任务总量固定的情况下，利用率与 makespan 成反比。设总任务时长为 $T_{\text{total}} = \sum_{e \in E}(e.\text{end\_time} - e.\text{start\_time})$，则：

$$\text{Utilization} = \frac{T_{\text{total}}}{\text{Makespan} \times N_{\text{arms}}}$$

提高并行度可以同时降低 makespan 和提高利用率。

### 2.4 Constraint Violations（约束违反数）

约束违反数衡量调度结果的合法性，统计执行日志中的约束违反事件数量。其完整计算公式为：

$$V = V_{\text{neg}} + V_{\text{overlap}}$$

其中两类违反的定义如下：

**（1）负时长违反** $V_{\text{neg}}$：任务的结束时间早于开始时间

$$V_{\text{neg}} = |\{e \in E : e.\text{end\_time} < e.\text{start\_time}\}|$$

**（2）同臂重叠违反** $V_{\text{overlap}}$：同一机械臂上两个任务的时间区间存在交集。具体计算方法为：对每个臂 $a$，收集其所有任务的时间区间 $I_a = \{(s_i, e_i)\}$，按 $s_i$ 升序排序后，检测相邻区间是否存在重叠：

$$V_{\text{overlap}} = \sum_{a \in \text{Arms}} \sum_{i=0}^{|I_a|-2} \mathbb{1}[e_i > s_{i+1}]$$

其中 $\mathbb{1}[\cdot]$ 为指示函数，当条件为真时取值 1，否则取值 0。注意此处采用严格大于（$>$）判断，即恰好相邻的区间（$e_i = s_{i+1}$）不计为违反。

理想情况下，约束违反数应为 0。非零值表明调度结果存在合法性问题，需要检查调度算法或仿真执行逻辑。


## 3. 基线方法

在定义了评估指标之后，本节介绍用于对比的基线方法及其数学模型。

### 3.1 MILP-Optimal

本次评估采用 **MILP-Optimal** 作为基线方法，使用 PuLP 库调用 CBC（Coin-or Branch and Cut）求解器。

MILP（Mixed Integer Linear Programming，混合整数线性规划）是调度优化的经典方法，通过将调度问题建模为线性规划问题并求解全局最优解。其数学模型如下：

**决策变量**：

- $x_{ij} \in \{0, 1\}$：任务 $i$ 是否分配给机械臂 $j$
- $s_i \geq 0$：任务 $i$ 的开始时间
- $C_{\max} \geq 0$：makespan

**目标函数**：

$$\min C_{\max}$$

**约束条件**：

1. 每个任务恰好分配给一个臂：
$$\sum_j x_{ij} = 1, \quad \forall i$$

2. Makespan 定义：
$$C_{\max} \geq s_i + d_i, \quad \forall i$$

3. 同臂任务不重叠（使用 Big-M 方法）：
$$s_i + d_i \leq s_j + M(1 - y_{ij}^k) + M(2 - x_{ik} - x_{jk}), \quad \forall i < j, \forall k$$

4. 任务依赖约束：
$$s_j \geq s_i + d_i, \quad \forall (i, j) \in \text{Precedence}$$

5. 旅行时间约束：
$$s_j \geq s_i + d_i + T_t[\text{loc}(i)][\text{loc}(j)], \quad \text{if } x_{ik} = x_{jk} = 1$$

其中 $d_i = T_e[i]$ 为任务 $i$ 的执行时间，$M$ 为足够大的常数（Big-M），$y_{ij}^k$ 为辅助二元变量，表示任务 $i$ 是否在任务 $j$ 之前在同一臂 $k$ 上执行。

### 3.2 基线结果

MILP 求解器在每个场景上独立运行，获得的最优 makespan 如下：

| 场景 | MILP 最优 Makespan (s) |
|------|:----------------------:|
| 1p | 584.9 |
| 2p | 931.0 |
| 3p | 642.8 |
| 4p | 465.0 |
| 5p | 490.9 |
| 6p | 489.8 |

注：MILP 最优解的质量受求解时间限制影响。CBC 求解器在默认配置下可能无法在合理时间内找到全局最优解，特别是在大规模场景中。因此，表中的"最优"应理解为"当前求解器配置下的最优"，而非理论全局最优。

### 3.3 其他基线方法

除 MILP-Optimal 外，系统还支持以下基线方法（通过 `BenchmarkRunner` 实现），可用于辅助分析：

| 基线方法 | 算法描述 | 时间复杂度 |
|---------|---------|-----------|
| **Random** | 随机分配任务至机械臂 | $O(T)$ |
| **Greedy** | 贪心分配，总是将任务分配给最先空闲的臂 | $O(T \cdot A)$ |
| **Genetic** | 遗传算法，通过 50 代进化优化分配方案 | $O(G \cdot P \cdot T \cdot A)$ |

其中 $T$ 为任务数，$A$ 为臂数，$G$ 为代数，$P$ 为种群大小。这些基线方法在本报告中未作为主要对比对象，但可用于辅助分析 Agent 调度的相对性能。

- 6 个场景中有 4 个的比率 $R > 1.0$，表明 Agent 调度在多数场景中劣于 MILP 最优解

- 4p 场景的比率最高（1.59x），可能是该场景的任务依赖结构对贪心分配算法不利

**2p 和 6p 场景比率低于 1.0 的可能原因**：

1. MILP 求解器在这些场景中可能未找到真正的全局最优解（受求解时间限制）
2. Agent 使用的 MRTA 旅行时间数据可能与 MILP 求解器使用的数据存在细微差异
3. 测量指标的计算方式可能存在差异（如时间窗口的定义）

### 5.4 任务成功率分析

任务成功率的分布特征如下：

| 统计量 | 值 |
|--------|-----|
| 最小值 | 72%（3p） |
| 最大值 | 88%（6p） |
| 均值 | 80.3% |
| 中位数 | 80% |
| 标准差 | 5.1% |

**分析**：

- 成功率与场景规模呈正相关，Pearson 相关系数 $r \approx 0.52$。计算过程如下：

$$r = \frac{\sum_{i=1}^{6}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{6}(x_i - \bar{x})^2 \cdot \sum_{i=1}^{6}(y_i - \bar{y})^2}} = \frac{25.00}{4.183 \times 11.46} \approx 0.52$$

其中 $x_i$ 为场景规模（工件数），$y_i$ 为成功率，$\bar{x} = 3.5$，$\bar{y} = 80.33\%$，$\sqrt{\sum(x_i-\bar{x})^2} = \sqrt{17.5} \approx 4.183$，$\sqrt{\sum(y_i-\bar{y})^2} = \sqrt{131.33} \approx 11.46$。相关系数 $r = 0.52$ 表示中等正相关，大规模场景提供更多重试机会，从而提升整体成功率。

- 3p 场景的成功率最低（72%），可能与该场景的任务依赖结构和异常频率有关
- 所有场景的约束违反数均为 0，表明失败任务均因执行异常（非约束违反）导致

### 5.5 资源利用率分析

| 统计量 | 值 |
|--------|-----|
| 最小值 | 40%（4p） |
| 最大值 | 57%（6p） |
| 均值 | 47.5% |
| 中位数 | 47% |
| 标准差 | 5.8% |

**分析**：

- 利用率与场景规模呈正相关，Pearson 相关系数 $r \approx 0.62$：

$$r = \frac{33.50}{4.183 \times 12.87} \approx 0.62$$

其中 $\bar{y} = 47.50\%$，$\sqrt{\sum(y_i-\bar{y})^2} = \sqrt{165.5} \approx 12.87$，$s_y = \sqrt{165.5/5} \approx 5.8\%$。相关系数 $r = 0.62$ 表示中等正相关，大规模场景中更多任务分配可提高机械臂利用率。

- 平均利用率 47.5% 表明机械臂约有一半时间处于空闲状态，存在较大的并行调度优化空间

为进一步理解各指标间的关系，计算指标间的 Pearson 相关系数矩阵：

|  | Makespan 比率 | 成功率 | 利用率 |
|--|:------------:|:------:|:------:|
| **Makespan 比率** | 1.00 | -0.30 | -0.56 |

- 成功率与利用率呈弱正相关（$r = 0.44$）：成功率高的场景往往利用率也略高


## 6. 统计分析

### 6.1 配对 t 检验方法

为评估 Agent 调度与 MILP 基线之间的差异是否具有统计显著性，我们采用配对 t 检验（Paired t-test）。配对 t 检验适用于同一组受试者（此处为同一场景）在两种条件（Agent vs MILP）下的测量值比较。

**假设设定**：

- 零假设 $H_0$：Agent 调度与 MILP 基线在 makespan 上无显著差异，即 $\mu_d = 0$
- 备择假设 $H_1$：Agent 调度与 MILP 基线在 makespan 上存在显著差异，即 $\mu_d \neq 0$

**检验统计量**：

$$t = \frac{\bar{d}}{s_d / \sqrt{n}}$$

其中：
- $\bar{d} = \frac{1}{n}\sum_{i=1}^{n} d_i$ 为差值均值
- $d_i = x_i^{\text{Agent}} - x_i^{\text{MILP}}$ 为第 $i$ 个场景的指标差值
- $s_d = \sqrt{\frac{1}{n-1}\sum_{i=1}^{n}(d_i - \bar{d})^2}$ 为差值标准差
- $n = 6$ 为场景数

**显著性水平**：$\alpha = 0.05$（双尾检验）

**方法论说明**：本检验使用 6 个场景的均值数据，每场景 5 次重复实验的均值作为该场景的代表值。需要指出的是，当前配对 t 检验的样本量为场景数（$n = 6$），而非总实验数（30）。各场景间存在规模差异（1p-6p），严格意义上不完全满足配对 t 检验的独立同分布假设。后续工作可考虑增加场景数量或采用 Wilcoxon 符号秩检验等非参数方法。

**实现方式**：系统优先使用 SciPy 的 `scipy.stats.ttest_rel` 函数；当 SciPy 不可用时，回退到正态近似：

```python
z = abs(mean_d / se)
p = 2.0 * (1.0 - 0.5 * (1.0 + math.erf(z / math.sqrt(2))))
```

### 6.2 Makespan 配对 t 检验

**原始数据**：

| 场景 | Agent Makespan (s) | MILP Makespan (s) | 差值 $d_i$ (s) |
|------|:------------------:|:-----------------:|:--------------:|
| 1p | 704.6 | 584.9 | +119.7 |
| 2p | 684.9 | 931.0 | -246.1 |
| 3p | 854.1 | 642.8 | +211.3 |
| 4p | 739.5 | 465.0 | +274.5 |
| 5p | 654.0 | 490.9 | +163.1 |
| 6p | 460.1 | 489.8 | -29.7 |

**计算过程**：

**步骤 1**：计算差值均值 $\bar{d}$

$$\bar{d} = \frac{119.7 + (-246.1) + 211.3 + 274.5 + 163.1 + (-29.7)}{6} = \frac{492.8}{6} = 82.13 \text{ (s)}$$

**步骤 2**：计算差值标准差 $s_d$

$$s_d = \sqrt{\frac{\sum_{i=1}^{6}(d_i - \bar{d})^2}{n - 1}} = \sqrt{\frac{(119.7-82.13)^2 + (-246.1-82.13)^2 + \cdots + (-29.7-82.13)^2}{5}}$$

$$= \sqrt{\frac{1411.33 + 107764.53 + 16685.39 + 37176.33 + 6556.81 + 12504.53}{5}} = \sqrt{\frac{182098.92}{5}} \approx 190.8 \text{ (s)}$$

**步骤 3**：计算 t 统计量

$$t = \frac{\bar{d}}{s_d / \sqrt{n}} = \frac{82.13}{190.8 / \sqrt{6}} = \frac{82.13}{77.90} \approx 1.05$$

**步骤 4**：确定自由度和 $p$ 值

自由度 $df = n - 1 = 5$，查 t 分布表得 $p \approx 0.34$。

**结论**：$p = 0.34 > \alpha = 0.05$，无法拒绝零假设。Agent 调度与 MILP 基线在 makespan 上的差异在统计上不显著。

**解释**：尽管平均 makespan 比率为 1.19x，但由于不同场景间的差异较大（标准差 0.28x），样本量（$n = 6$）不足以检测到统计显著的差异。增加场景数量或重复次数可能提高检验功效。

### 6.3 其他指标的统计检验

|------|----------|-------|-----|-----|--------|
| Makespan | +82.13s | 190.8s | 1.05 | 0.34 | 不显著 |
| Success Rate | — | — | — | — | 无 MILP 基线 |
| Utilization | — | — | — | — | 无 MILP 基线 |
| Violations | 0 | 0 | — | — | 无差异 |

注：任务成功率和资源利用率无法与 MILP 基线进行配对 t 检验，因为 MILP 求解器仅输出最优 makespan，不涉及执行成功率和利用率。约束违反数在所有场景中均为 0，无需检验。

### 6.4 效应量分析

效应量（Effect Size）用于衡量差异的实际意义，不受样本量影响。采用 Cohen's $d$ 作为效应量指标：

$$d = \frac{\bar{d}}{s_d} = \frac{82.13}{190.8} \approx 0.43$$

根据 Cohen 的分类标准：
- $|d| < 0.2$：小效应
- $0.2 \leq |d| < 0.5$：中等效应
- $|d| \geq 0.5$：大效应

本实验的 Cohen's $d = 0.43$ 属于中等效应，表明 Agent 与 MILP 之间的差异具有实际意义，但当前样本量不足以在统计上检测到这一差异。

### 6.5 统计功效分析

当前实验设计的统计功效（Power）分析：

- 样本量：$n = 6$（场景数）
- 效应量（Cohen's $d$）：$d = 0.44$（中等效应）
- 显著性水平：$\alpha = 0.05$
- 统计功效：约 0.15（较低）

统计功效的计算基于非中心 t 分布：

$$\text{Power} = P(|T| > t_{\alpha/2, df} \mid \delta = d\sqrt{n})$$

其中 $\delta = 0.43 \times \sqrt{6} \approx 1.05$ 为非中心参数。

要达到 80% 的统计功效（Power = 0.8），所需样本量可通过以下公式估算：

$$n_{\text{required}} \approx \left(\frac{z_{\alpha/2} + z_{\beta}}{d}\right)^2 = \left(\frac{1.96 + 0.84}{0.44}\right)^2 \approx 40.3$$

因此，当前实验的"不显著"结果更可能是因为样本量不足（$n = 6 \ll 40$），而非效应不存在。

### 6.6 置信区间

尽管 $p$ 值不显著，我们仍可计算差值均值的 95% 置信区间，以量化估计的不确定性：

$$\bar{d} \pm t_{\alpha/2, df} \cdot \frac{s_d}{\sqrt{n}} = 82.13 \pm 2.571 \times 77.90 = 82.13 \pm 200.3$$

即 95% 置信区间为 $[-118.2, 282.4]$ 秒。该区间包含 0，与 $p > 0.05$ 的结论一致。区间较宽（跨度约 401 秒）反映了当前样本量下估计的不确定性。


## 7. 结论

基于 30 次实验的评估结果，我们对四个研究问题做出如下回答：

1. **RQ1（调度质量）**：Agent 调度的平均 makespan 为 MILP 最优解的 1.19 倍（Cohen's $d = 0.43$，中等效应）。在 6 个场景中有 4 个劣于 MILP，2 个优于 MILP。考虑到 Agent 系统使用贪心算法而非全局优化，1.19x 的比率在工程上可接受。

2. **RQ2（可靠性）**：平均任务成功率为 80%，平均资源利用率为 47%。成功率表明系统具备基本的执行可靠性，但仍有 20% 的任务失败需要通过反馈闭环和异常处理来优化。利用率表明系统存在较大的并行调度优化空间。

3. **RQ3（场景规模影响）**：场景规模与资源利用率呈正相关（$r = 0.62$），与 makespan 比率无明显线性关系。大规模场景（6p）的表现优于部分中等规模场景（4p），表明系统的贪心分配算法在某些场景结构下可能存在局部最优陷阱。

4. **RQ4（统计显著性）**：配对 t 检验显示 Agent 与 MILP 在 makespan 上的差异不具统计显著性（$p = 0.34$），主要原因是样本量不足（$n = 6$）。效应量分析表明差异具有实际意义（$d = 0.43$），增加场景数量至约 40 个可提高检验功效至 80%。

系统的主要优势包括：接受自然语言指令输入的灵活性、闭环反馈的自适应性、四级渐进式恢复策略的鲁棒性，以及模块化架构的可扩展性。

### D. 配对 t 检验详细计算

以下为 Makespan 配对 t 检验的完整计算过程，包括中间步骤：

**原始数据与差值计算**：

| 场景 | $x_i^{\text{Agent}}$ | $x_i^{\text{MILP}}$ | $d_i = x_i^{\text{Agent}} - x_i^{\text{MILP}}$ | $d_i - \bar{d}$ | $(d_i - \bar{d})^2$ |
|------|:-------------------:|:-------------------:|:--------------------------------------------:|:---------------:|:-------------------:|
| 1p | 704.6 | 584.9 | +119.7 | +37.6 | 1413.76 |
| 2p | 684.9 | 931.0 | -246.1 | -328.2 | 107702.44 |
| 3p | 854.1 | 642.8 | +211.3 | +129.2 | 16687.36 |
| 4p | 739.5 | 465.0 | +274.5 | +192.4 | 37171.36 |
| 5p | 654.0 | 490.9 | +163.1 | +81.0 | 6561.00 |
| 6p | 460.1 | 489.8 | -29.7 | -111.8 | 12499.24 |

**步骤 1**：差值均值

$$\bar{d} = \frac{119.7 - 246.1 + 211.3 + 274.5 + 163.1 - 29.7}{6} = \frac{492.8}{6} = 82.13 \text{ (s)}$$

**步骤 2**：差值平方和

$$\text{SS}_d = \sum_{i=1}^{6}(d_i - \bar{d})^2 = 1413.76 + 107702.44 + 16687.36 + 37171.36 + 6561.00 + 12499.24 = 182035.16$$

**步骤 3**：差值方差和标准差

$$s_d^2 = \frac{\text{SS}_d}{n - 1} = \frac{182035.16}{5} = 36407.03$$

$$s_d = \sqrt{36407.03} = 190.81 \text{ (s)}$$

**步骤 4**：标准误

$$\text{SE} = \frac{s_d}{\sqrt{n}} = \frac{190.81}{\sqrt{6}} = \frac{190.81}{2.449} = 77.91 \text{ (s)}$$

**步骤 5**：t 统计量

$$t = \frac{\bar{d}}{\text{SE}} = \frac{82.13}{77.91} = 1.054$$

**步骤 6**：查表确定 $p$ 值

自由度 $df = n - 1 = 5$，$\alpha = 0.05$（双尾），临界值 $t_{0.025, 5} = 2.571$。

由于 $|t| = 1.054 < 2.571 = t_{0.025, 5}$，无法拒绝零假设。

查 t 分布表，$p \approx 0.34$（双尾）。

**结论**：$p = 0.34 > \alpha = 0.05$，差异不显著。

### E. 置信区间计算详情

**95% 置信区间**：

$$\bar{d} \pm t_{\alpha/2, df} \cdot \text{SE} = 82.13 \pm 2.571 \times 77.91 = 82.13 \pm 200.27$$

$$\text{CI}_{95\%} = [-118.14, 282.40] \text{ (s)}$$

**解读**：我们有 95% 的置信度认为，Agent 调度与 MILP 基线的真实 makespan 差异在 $[-118.14, 282.40]$ 秒之间。该区间包含 0，与 $p > 0.05$ 的结论一致。

**90% 置信区间**（供参考）：

$$\bar{d} \pm t_{0.05, 5} \cdot \text{SE} = 82.13 \pm 2.015 \times 77.91 = 82.13 \pm 156.99$$

$$\text{CI}_{90\%} = [-74.86, 239.12] \text{ (s)}$$

### F. 统计功效计算详情

统计功效（Power）是指在备择假设为真时，正确拒绝零假设的概率。对于配对 t 检验，功效计算基于非中心 t 分布。

**参数设定**：
- 效应量：$d = 0.44$
- 样本量：$n = 6$
- 非中心参数：$\delta = d \sqrt{n} = 0.44 \times 2.449 = 1.078$
- 显著性水平：$\alpha = 0.05$（双尾）
- 自由度：$df = 5$

**功效计算**：

$$\text{Power} = P(|T| > t_{\alpha/2, df} \mid \delta = 1.078)$$

使用非中心 t 分布的近似公式：

$$\text{Power} \approx 1 - \Phi(t_{\alpha/2, df} - \delta) + \Phi(-t_{\alpha/2, df} - \delta)$$

$$\approx 1 - \Phi(2.571 - 1.078) + \Phi(-2.571 - 1.078)$$

$$\approx 1 - \Phi(1.493) + \Phi(-3.649)$$

$$\approx 1 - 0.932 + 0.0001 \approx 0.068$$

实际功效约为 0.15（考虑 t 分布与正态分布的差异），属于低功效水平。

**达到 80% 功效所需样本量**：

$$n_{\text{required}} = \left(\frac{z_{\alpha/2} + z_{\beta}}{d}\right)^2 = \left(\frac{1.96 + 0.84}{0.44}\right)^2 = \left(\frac{2.80}{0.44}\right)^2 = 6.36^2 \approx 40.5$$

即需要约 41 个场景才能达到 80% 的统计功效。
